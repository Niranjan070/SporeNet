# SporeNet Parking Lot (Out-of-Scope Ideas)

This document tracks promising features, architectural enhancements, and hardware integrations that are currently out of scope for the Phase 0–4 MVP but reserved for future iterations.

---

| Item ID | Title | Description | Target Phase / Future Horizon | Status |
| :---: | :--- | :--- | :--- | :---: |
| **PL-01** | Event-Triggered Adaptive Sampling Cadence | Dynamically increase Raspberry Pi sampling cadence or field slide collection prompts when high infection risk weather windows are detected. | Post-MVP / Version 2.0 | Deferred |
| **PL-02** | Automated In-Trap Microscope Hardware | Integrate automated motorized optical microscope inside the physical spore trap for real-time edge image capture (eliminating weekly manual field collection). | Version 3.0 Hardware Redesign | Deferred |
| **PL-03** | Real-Time qPCR Molecular Validation | Cross-validate YOLO microscopic spore counts against automated quantitative PCR molecular assay readings for high-precision strain verification. | Lab Research Phase | Deferred |
| **PL-04** | Autonomous Drone Aerial Spore Trapping | Deploy autonomous UAVs equipped with airborne bio-aerosol collectors to monitor spore density at different canopy heights. | Future Field Expansion | Deferred |
| **PL-05** | Native Mobile App & Push Notification Gateway | Build dedicated iOS/Android applications with SMS/WhatsApp push notification gateways for low-connectivity rural farm workers. | Production Deployment | Deferred |
| **PL-06** | Multi-Field Regional Farm Mesh Network | Extend single-field LangGraph orchestration to federated multi-farm regional outbreak tracking across agricultural districts. | Regional Scale-up | Deferred |
